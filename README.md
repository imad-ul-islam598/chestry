# Chestry ♟️

Chestry is a minimalist, elegant Chess application built for those who appreciate the strategic depth of chess combined with a sophisticated, distraction-free environment.

**Live Demo:** [https://chestry-69373810036.asia-southeast1.run.app/](https://chestry-69373810036.asia-southeast1.run.app/)

## ✨ Features

- **Full Chess Engine Logic:** Support for all standard moves including:
  - **Castling:** Secure your king and develop your rooks.
  - **En Passant:** Catch pawns moving two squares.
  - **Promotion:** Advance your pawns to powerful pieces.
- **Game State Detection:** Real-time monitoring for Check, Checkmate, Stalemate, and Draw conditions.
- **Minimalist Design:** A clean, modern UI with smooth transitions powered by `motion`.
- **Relaxing Atmosphere:** Gentle background music and haptic-style sound design to enhance focus.
- **Smart Bot:** Play against an integrated AI opponent.
- **Educational Guide:** Built-in rules and guide for beginners.

## 🚀 Tech Stack

- **Frontend:** React + TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Motion (formerly Framer Motion)
- **Icons:** Lucide React
- **Build Tool:** Vite

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/imadulislam598/chestry.git
   cd chestry
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📜 How to Play

1. **Movement:** Click a piece to select it, then click a highlighted square to move.
2. **Rules:** Refer to the in-app **Guide** section for a detailed breakdown of movement and special rules.
3. **Winning:** The game ends when a king is in checkmate or a draw condition (like stalemate or insufficient material) is met.
